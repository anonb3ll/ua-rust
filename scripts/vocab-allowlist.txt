# Intended matches for scripts/vocab-check.sh: a path glob, then optionally
# whitespace and an extended regex the matching line must also match. A path
# alone allows every match in that file. The optional trailing field scopes the
# entry to one pattern class ("vocab" for the role names, "private" for
# addresses, home paths and tailnet names): an entry scoped to one class never
# silences a finding of the other class, even on the same line.
